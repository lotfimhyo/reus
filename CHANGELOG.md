All notable changes to Reus will be recorded here. The project follows a
human-reviewed release process: a change is not considered released solely
because it exists on a branch.

## Unreleased

### Added

The private GitHub preparation baseline includes an English README, architecture
and quick-start documentation, contribution and conduct standards, security and
governance policies, public-claims evidence requirements, GitHub issue forms,
quality-gate CI, CodeQL analysis, secret scanning, dependency-update automation,
and an official Reulink brand policy.

### Security

The release surface explicitly excludes secrets, runtime state, payment data,
unattended hosting purchases, and remote-device access. The selected source
snapshot includes the locally validated Reus core and its test suite.
